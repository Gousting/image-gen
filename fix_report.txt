## 任务二：修 bug —— 审查循环不达标时返回「最后一次」而非「最高分」

### 改动点
- `review/vlm_review.py` 的 `review_with_retry`：
  - 循环内跟踪 `best`（当前最高分的 ReviewResult），每次生成后若 `review.score > best.score` 则更新。
  - 达标（>= threshold）立即返回；循环结束返回 `best`（最高分那次），不再返回 `last`。
  - `meta` 新增 `"attempt_scores"`（list，记录每次尝试分数，如 `[62, 74, 55]`）。
  - 返回 `best` 时补齐总尝试次数 `attempts` 与完整的 `attempt_scores`。
  - 修正函数 docstring 与末尾注释，去掉「返回最后一次（得分最高者由调用方决定）」自相矛盾描述。
- `tests/test_vlm_review.py`（新建）：
  - `test_review_with_retry_returns_best`：mock 连续返回 74、55，断言返回 74 分那次、
    `meta.attempt_scores == [74.0, 55.0]`、`attempts == 2`。
  - `test_review_with_retry_returns_early_on_pass`：60、88，第二次达标立即返回（回归保护）。

### 测试结果
pytest 全绿（21 passed）。

## 任务三：设计完善 —— VLM 审查返回分维度评分（支持针对性重生成）

### 改动点
- `review/vlm_review.py`：
  - `_SCORE_PROMPT` 返回格式改为 `{score, dimensions{...5 维...}, opinion}`。
  - `ReviewResult` 新增 `dimensions: dict[str, float] = field(default_factory=dict)`。
  - `score()` 用 `_parse` 解析出的 dimensions 填充 `ReviewResult.dimensions`。
  - `_parse` 返回 `(score, opinion, dimensions)`；dimensions 缺失/非法时降级为空 dict，
    不影响 score 阈值判断（向后兼容）。
- `tests/test_vlm_review.py` 新增：
  - `test_parse_dimensions`：5 维解析正确。
  - `test_parse_missing_dimensions_falls_back_to_empty`：返回体缺 dimensions 正常解析为空 dict。
  - `test_parse_tolerates_markdown_fence`：容忍 markdown 代码块包裹。

### 测试结果
pytest 全绿（24 passed）。

## 任务四：设计完善 —— 暴露 Z-Image size 档位（支持更高分辨率出图）

### 改动点
- `providers/base.py`：`GenRequest` 新增 `size: str | None = None`，docstring 说明取值来自
  object_info 的 size 档位。
- `providers/comfyui_zimage.py` 的 `_build_workflow`：size 用 `req.size or self.default_size`，
  替换写死的 `self.default_size`；config.yaml 的 `zimage.size` 仍作默认回退。
- `config.yaml`：zimage 段加注释说明 size 档位可选值（以 object_info 实际返回为准）。
- `tests/test_providers.py` 新增：
  - `test_zimage_size_override`：`size="large"` → workflow 里 EmptyZImageLatentImage 的 `size == "large"`。
  - `test_zimage_size_default_fallback`：`size=None` → 回退 config 默认 `"medium (recommended)"`。
  - `test_genrequest_defaults` 补充断言 `size` 默认 `None`。

### object_info 实际返回的 size 档位
`GET http://127.0.0.1:8188/object_info` 中节点 `EmptyZImageLatentImage //ZImagePowerNodes`
的 `size` 输入（COMBO，default `"medium (recommended)"`）实际可选值：

- `"small"`
- `"medium (recommended)"`
- `"large"`

（与任务书预期一致，无其它档位。）

### 测试结果
pytest 全绿（26 passed）。
