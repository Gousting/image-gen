## 七、新发现问题 / 观察（非阻塞）

1. **任务书示例 `size="medium"` 与真实 COMBO 值不符**：真实可选值为
   `small / medium (recommended) / large`，裸 `"medium"` 会被 ComfyUI 拒绝。代码本身
   （默认值 `"medium (recommended)"`、fix_report）是对的，属任务书示例笔误。

2. **cli.py --review 未打印 5 维度分 / attempt_scores**：审查逻辑（review/vlm_review.py）已正确
   返回 dimensions 与 meta.attempt_scores，但 CLI 展示层只打印 score/attempts/seed/opinion。
   本次用 verify_vlm_review.py 补齐维度打印。属「展示层」小缺口，不影响审查闭环本身，
   后续可考虑在 CLI 补一行维度输出。

3. **Z-Image 塔罗牌「标题文字」仍会被裁切/难辨认**：高塔牌 text_legibility=70，VLM opinion
   明确指出「底部标题文字被裁切难以辨认」——这是 Z-Image「画面内文字易乱码」坑（README 坑 #3）
   在塔罗牌场景的自然体现，text_legibility 维度确实捕捉到了。若牌面标题重要，需后续在 prompt
   或后期处理上处理（本次范围外）。

4. **阈值 75 对 ink_frenzy 偏严**：实测 3 组审查 attempts 为 2~4 次，多数首张 56~73 分需
   重生成才能过线，出图成本偏高。阈值与 max_retries 均可配（config.yaml），属调参问题而非 bug。
